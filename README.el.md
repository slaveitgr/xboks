Το xboks φέρνει στο Linux ένα περιβάλλον βασισμένο στην εφαρμογή Xbox: αρχική οθόνη, περιήγηση στο Game Pass, συγκεντρωτική βιβλιοθήκη, Store, σελίδες παιχνιδιών, ουρά εγκατάστασης, ρυθμίσεις και οδηγό επιφάνειας εργασίας. Το **xboks Engine** παρέχει το διαχειριζόμενο backend και την ενσωμάτωση Proton/runtime για τα υποστηριζόμενα παιχνίδια. Η [αρχική βάση και οι άδειες](#με-βάση-τα-xodus-και-xodus-nexus) αναφέρονται παρακάτω.

> **Ανεξάρτητο έργο υπό ανάπτυξη.** Στόχος είναι η πιστή αναπαραγωγή της εμφάνισης και της συμπεριφοράς του Windows Xbox client. Η δουλειά συνεχίζεται. Το xboks είναι ανεπίσημο· δεν παρουσιάζεται ως ολοκληρωμένο αντίγραφο όλων των λειτουργιών των Windows ούτε ως λύση συμβατή με κάθε παιχνίδι.

Ο προεπιλεγμένος φάκελος εγκατάστασης παιχνιδιών είναι **`~/Games/Xboks`**. Η παλιά προεπιλογή `~/Games/Xodus Nexus` αλλάζει στις ρυθμίσεις· οι προσαρμοσμένες διαδρομές διατηρούνται και τα υπάρχοντα αρχεία παιχνιδιών δεν μετακινούνται αυτόματα.

Η **0.3.14** προσθέτει το παράθυρο επιλογής περιεχομένου πριν από την εγκατάσταση: απαιτούμενο κυρίως παιχνίδι, **Επόμενο**, πραγματική θέση εγκατάστασης και τελικό **Εγκατάσταση**. Τα εναλλακτικά πακέτα παραμένουν επιλογή ενός πακέτου. Προαιρετικά γλωσσικά πακέτα/τμήματα και μεγέθη δίσκου χρειάζονται επιπλέον δεδομένα από τον engine και δεν εμφανίζονται ως λειτουργικές επιλογές χωρίς αυτά.

Προστέθηκε επίσης η ξεχωριστή οθόνη συμβατότητας συσκευών χειρός στις σελίδες Store και εγκατεστημένων παιχνιδιών. Διαβάζει την πραγματική αξιολόγηση από τη δημόσια υπηρεσία Xbox χωρίς διαπιστευτήρια λογαριασμού. Η αξιολόγηση αφορά συσκευές χειρός Windows· δεν αποτελεί πιστοποίηση Linux/Proton ή πρόβλεψη επιδόσεων αυτού του PC. Όταν λείπει, παραμένει άγνωστη. Η [ανάλυση συμβατότητας συσκευών χειρός](docs/analysis/reference/handheld-compatibility.md) περιγράφει τα αρχικά δεδομένα, γραφικά και συμπεριφορές.

### Φωνή: τι υπάρχει και τι ακολουθεί

Η τοπική δοκιμή μικροφώνου βρίσκεται στις ρυθμίσεις Ήχου και στην καρτέλα Ήχου του οδηγού. Η λήψη ξεκινά μόνο μετά την **Έναρξη δοκιμής**. Η ακρόαση αρχίζει απενεργοποιημένη· το κλείσιμο ή η απόκρυψη της δοκιμής ελευθερώνει το μικρόφωνο. Η επιλογή συσκευών/εξόδου και η καταστολή θορύβου εξαρτώνται από όσα εκθέτουν η επιφάνεια εργασίας και το Chromium. Ο ήχος της δοκιμής δεν καταγράφεται ούτε αποστέλλεται στο Xbox και το push to talk λειτουργεί τοπικά στο παράθυρό της.

Για ανεξάρτητη φωνητική συνομιλία σε Xbox party χρειάζονται ακόμη η σύνδεση με τις υπηρεσίες δημιουργίας/συμμετοχής και αυθεντικοποίησης, η εγγενής υπηρεσία ήχου Linux και δοκιμές μεταξύ συσκευών. Η εξάρτηση του αρχικού πακέτου `xCommsUwp` → `PartyWin` και τα πεδία ταυτότητας/δικτύου PlayFab τεκμηριώνονται στην [ανάλυση φωνής party](docs/analysis/reference/party-voice.md). Η πρόσβαση στο μικρόφωνο, μια λίστα συμμετεχόντων ή η επιτυχής μεταγλώττιση μιας βιβλιοθήκης δεν αποδεικνύουν λειτουργική φωνή Xbox.

## Ξεκίνημα

Χρειάζονται **Node 22**, npm και επιφάνεια εργασίας Linux που μπορεί να εκτελέσει Electron. Η τρέχουσα μεταγλώττιση του backend στοχεύει Linux x86_64.

```sh
git clone https://github.com/slaveitgr/xboks.git
cd xboks
npm ci
npm run dev
```

Για προεπισκόπηση με δείγματα λογαριασμού/βιβλιοθήκης:

```sh
XBOKS_DEMO=1 npm run dev
```

Το demo δεν συνδέεται σε πραγματικό λογαριασμό, δεν εγκαθιστά και δεν εκτελεί πραγματικά παιχνίδια. Μπορεί να αντλεί δημόσια δεδομένα και εικόνες από το Store.

Για κανονική χρήση, ρυθμίστε το **xboks Engine** και το κοινό runtime στις Ρυθμίσεις και συνδεθείτε από τη σελίδα Λογαριασμού. Τα υποστηριζόμενα παιχνίδια χρησιμοποιούν το επιλεγμένο Proton/runtime· η διαθεσιμότητα εξαρτάται από τα δικαιώματα λογαριασμού, τις άδειες χρήσης, τη συμβατότητα του runtime και το ίδιο το παιχνίδι. Το runtime αποθηκεύεται από προεπιλογή στο `<XDG data home>/xboks/engine/runtimes` και το backend στον φάκελο `engine/` του προφίλ xboks.

Οι έλεγχοι ενημερώσεων launcher, backend και runtime χρησιμοποιούν πλέον τα **[releases του slaveitgr/xboks](https://github.com/slaveitgr/xboks/releases)**. Δεν καταφεύγουν σε εκτελέσιμα άλλων upstream projects και οι λήψεις runtime δεν απαιτούν σύνδεση GitHub. Πρέπει να έχει δημοσιευτεί πλήρες συμβατό release του xboks για να εγκατασταθεί έτσι· η αλλαγή καναλιού δεν δημιουργεί από μόνη της releases. Η σύνδεση Microsoft, τα αρχεία παιχνιδιών, ο κατάλογος και τα απαραίτητα redistributables συνεχίζουν να χρησιμοποιούν τις πραγματικές υπηρεσίες των προμηθευτών τους. Δείτε τον [έλεγχο λήψεων και προέλευσης κώδικα](docs/engine-downloads.md).

### Έλεγχος και δημιουργία πακέτου

```sh
npm run typecheck
npm test
npm run build
npm run dist
```

Το `npm run build` περιλαμβάνει έλεγχο τύπων και όλες τις δοκιμές του launcher. Το `npm run dist` επαναλαμβάνει το build και δημιουργεί AppImage στον φάκελο `release/`· δεν δημοσιεύει GitHub release. Ένα επιτυχημένο πακέτο σε έναν υπολογιστή δεν επιβεβαιώνει συμβατότητα με κάθε διανομή Linux.

### Προαιρετικό social companion — backend 0.3.0

Οι φίλοι/συνομιλίες χρησιμοποιούν το επιλεγμένο backend όταν αυτό υποστηρίζει social. Ένα πακέτο μπορεί εναλλακτικά να περιλαμβάνει το **social companion 0.3.0**, χωρίς αντικατάσταση του backend παιχνιδιών. Διαβάζει τα υπάρχοντα συμβατά διαπιστευτήρια λογαριασμού χωρίς εγγραφή ή ανανέωσή τους· αν έχουν λήξει, απαιτείται η κανονική ανανέωση/σύνδεση από τον Λογαριασμό.

Για μεταγλώττιση του companion από την καθορισμένη έκδοση πηγαίου κώδικα, χρησιμοποιήστε το Rust toolchain του [`assets/backend-source.lock.json`](assets/backend-source.lock.json) και τις εξαρτήσεις του [`scripts/BACKEND.md`](scripts/BACKEND.md), μαζί με το `protoc`:

```sh
mkdir -p work outputs
node scripts/build-backend.mjs --work work/social-build --output outputs/social-backend
node scripts/bundle-social-backend.mjs \
  --binary work/social-build/target/release/xodus-cli \
  --license work/social-build/source/LICENSE \
  --source-archive outputs/social-backend/xboks-engine-backend-0.3.0-linux-x86_64-source.tar.xz
npm run dist
```

Το εσωτερικό αποτέλεσμα μεταγλώττισης Cargo διατηρεί το όνομα `xodus-cli`· το εργαλείο συσκευασίας αποθηκεύει τα επαληθευμένα bytes ως `xboks-engine`. Οι φάκελοι εργασίας/εξόδου πρέπει να είναι νέοι· το εργαλείο συσκευασίας επίσης αρνείται να αντικαταστήσει το `assets/social-backend/`. Τα παραγόμενα εκτελέσιμα και το αρχείο του αντίστοιχου πηγαίου κώδικα μένουν εκτός Git. Το companion ελέγχεται με hash και περιορισμένο έλεγχο βοήθειας, δεν χρησιμοποιείται για σύνδεση ή εκτέλεση παιχνιδιών και δεν ενεργοποιεί φωνή party. Οι εξαρτήσεις OpenSSL 4/glibc του τοπικού companion και τα όρια επαλήθευσης καταγράφονται στην [αναφορά social/συστήματος](docs/analysis/social-system-integration.md).

## Fullscreen Experience & Game Bar

**Η 0.3.13 προσθέτει προαιρετικό πρωτότυπο Fullscreen Experience για το GNOME Shell 51.** Στο παράθυρο επιφάνειας εργασίας, επάνω δεξιά εμφανίζεται μόνο το κουμπί **Λειτουργία Xbox**. Σε πλήρη οθόνη, αντικαθίσταται από το ρολόι και τη διαθέσιμη κατάσταση μπαταρίας/τροφοδοσίας. Ποσοστό, φόρτιση και εξωτερική τροφοδοσία προέρχονται από το Linux· οι άγνωστες τιμές παραμένουν άγνωστες. Δίπλα στο κουμπί εισόδου δεν εμφανίζονται ρολόι επιφάνειας εργασίας ή επινοημένη ένδειξη φόρτισης.

Όταν η επέκταση έχει εγκατασταθεί, αναγνωριστεί από το GNOME και ενεργοποιηθεί, ρητό αίτημα από το εστιασμένο παράθυρο xboks μπορεί να κρύψει προσωρινά τα υποστηριζόμενα στοιχεία του GNOME Shell. Η μόνιμη τοπική σύνδεση της εφαρμογής διατηρεί τη λειτουργία και την αποδεσμεύει κατά την έξοδο ή την απώλεια σύνδεσης. Το **Ctrl+Super+Escape** είναι η συντόμευση επαναφοράς έκτακτης ανάγκης· για είσοδο πρέπει να είναι διαθέσιμη. Το κλείδωμα ή η απενεργοποίηση της επέκτασης επαναφέρουν επίσης τις αλλαγές της. Το ξεκλείδωμα δεν ενεργοποιεί ξανά αυτόματα τη λειτουργία.

Οι υπάρχουσες εφαρμογές, ο compositor GNOME και οι υπηρεσίες επιφάνειας εργασίας συνεχίζουν να εκτελούνται. Η λειτουργία **δεν** ελευθερώνει τη RAM τους, δεν τερματίζει εφαρμογές παρασκηνίου και δεν δημιουργεί ξεχωριστή gaming συνεδρία. Χωρίς την επέκταση, παραμένει διαθέσιμη η απλή πλήρης οθόνη παραθύρου και η εφαρμογή ενημερώνει ότι η λειτουργία Xbox του συστήματος δεν είναι διαθέσιμη. Η πλήρης οθόνη ενός παραθύρου δεν αποδεικνύει ενεργή ενσωμάτωση GNOME.

### Εγκατάσταση προαιρετικής επέκτασης GNOME

Από το source checkout σε **GNOME Shell 51**, επιλέξτε νέο φάκελο προετοιμασίας:

```sh
python3 scripts/desktop/stage-gnome-experience.py \
  --output work/gnome-experience/install-stage --install
```

Το εργαλείο ελέγχει την έκδοση Shell, αρνείται υπάρχοντα φάκελο επέκτασης και εγκαθιστά την επέκταση **ανενεργή**. Δεν την ενεργοποιεί, δεν εισέρχεται σε λειτουργία Xbox, δεν αλλάζει ρυθμίσεις επιφάνειας εργασίας και δεν τερματίζει τη συνεδρία. Χωρίς `--install`, προετοιμάζει μόνο τα αρχεία. Άλλες κύριες εκδόσεις GNOME δεν υποστηρίζονται από αυτό το πρωτότυπο.

Το πακέτο περιλαμβάνει επίσης τον πηγαίο κώδικα της επέκτασης και το εργαλείο εγκατάστασης. Από αποσυμπιεσμένο AppImage που περιέχει φάκελο `resources/`, η αντίστοιχη εντολή είναι:

```sh
python3 resources/desktop/stage-gnome-experience.py \
  --source resources/gnome-extension/xboks-experience@slaveitgr.github.io \
  --output /tmp/xboks-experience-install-stage --install
```

Ο φάκελος εξόδου πρέπει να είναι νέος· καμία εντολή δεν αντικαθιστά υπάρχουσα επέκταση.

Μια **νέα τοπική επέκταση χρειάζεται νέα συνεδρία GNOME για να αναγνωριστεί**. Αποθηκεύστε την εργασία σας και αποσυνδεθείτε/συνδεθείτε ξανά όταν το επιλέξετε· το εργαλείο και η εφαρμογή δεν το κάνουν αυτόματα. Η εγκατάσταση από μόνη της δεν ενεργοποιεί την επέκταση στην τρέχουσα συνεδρία. Μετά τη νέα σύνδεση:

```sh
gnome-extensions enable xboks-experience@slaveitgr.github.io
gnome-extensions info xboks-experience@slaveitgr.github.io
```

Η ενεργοποίηση κάνει διαθέσιμη την ενσωμάτωση· η είσοδος γίνεται όταν επιλέξετε **Λειτουργία Xbox** στο xboks. Για απενεργοποίηση της επέκτασης:

```sh
gnome-extensions disable xboks-experience@slaveitgr.github.io
```

Δείτε τις [οδηγίες και το πρωτόκολλο επέκτασης](desktop/gnome/xboks-experience@slaveitgr.github.io/README.md) και την [αρχιτεκτονική συνεδριών Linux](docs/analysis/fullscreen-experience-linux.md). Η ξεχωριστή gaming συνεδρία Gamescope/Kiosk για τη διανομή παραμένει επόμενο βήμα. Το `XBOKS_FULLSCREEN_EXPERIENCE=1` δηλώνει ήδη διαμορφωμένη συνεδρία διανομής· η απλή δήλωσή του δεν δημιουργεί τέτοια συνεδρία.

Οι αυτοματοποιημένες δοκιμές καλύπτουν ιδιοκτησία/επαναφορά, προσομοιωμένη συμπεριφορά Shell, τον πραγματικό GJS helper με ελεγχόμενη υπηρεσία σε απομονωμένο D-Bus, μεταβάσεις πλήρους οθόνης και καταστάσεις μπαταρίας/επάνω γραμμής. Είναι **δοκιμές με ελεγχόμενα δεδομένα και έλεγχοι πρωτοκόλλου**. Η πραγματική επαναφορά panel/dock, το κλείδωμα/ξεκλείδωμα, οι πολλαπλές οθόνες, οι φυσικές συντομεύσεις/χειριστήρια και η συμπεριφορά πάνω από παιχνίδια χρειάζονται ακόμη δοκιμές αποδοχής.

### Πλοήγηση χειριστηρίου και Game Bar

Το D-pad/αριστερός μοχλός μετακινεί την εστίαση, το A επιλέγει, το B επιστρέφει και τα LB/RB αλλάζουν την ενεργή σελίδα, καρτέλα ή ενότητα του οδηγού. Ποντίκι και πληκτρολόγιο παραμένουν διαθέσιμα. Ανοίξτε τον οδηγό από το κουμπί της εφαρμογής, με **Ctrl+G** μέσα στην εφαρμογή, με το κουμπί Guide όταν το εκθέτει το λειτουργικό ή με **`--game-bar`**. Για αντιστοίχιση **Win+G** στο GNOME με υπάρχον AppImage:

```sh
python3 scripts/desktop/install-gnome-gamebar.py \
  --command '/absolute/path/to/xboks.AppImage --game-bar'
```

Το εργαλείο συντόμευσης διατηρεί τις άλλες αντιστοιχίσεις και αρνείται υπάρχουσα σύγκρουση Win+G. Ο οδηγός παραμένει ξεχωριστό παράθυρο Electron. Η επέκταση Fullscreen Experience **δεν** τον μετατρέπει σε εγγενές overlay του compositor: η καθολική εμφάνιση/είσοδος του Game Bar πάνω από εξωτερικά παιχνίδια στο Wayland εκκρεμεί. Η ένταση συστήματος χρησιμοποιεί PipeWire/WirePlumber (`wpctl`)· τα στιγμιότυπα καταγράφουν το παράθυρο xboks, όχι οποιοδήποτε παιχνίδι ή ολόκληρη την επιφάνεια εργασίας.

## Ανακατασκευή και επαλήθευση

Η οπτική αναφορά είναι η **εφαρμογή Xbox Windows 2610.1001.20.0 σε Xbox mode** και τα στιγμιότυπα που έχουν δοθεί. Η [βιβλιοθήκη αναφοράς](docs/analysis/reference/README.md) συνδέει παρατηρήσεις από screenshots, αποκωδικοποιημένους πόρους, κανόνες ελέγχων/πλοήγησης, native μεταδεδομένα και οδηγίες υλοποίησης. Ο [πίνακας επαλήθευσης](docs/analysis/reference/verification-matrix.json) διαχωρίζει στατικά ευρήματα, παρατηρήσεις στα Windows και δοκιμασμένη συμπεριφορά στο Linux.

Αφετηρίες:

- [Οδηγός υλοποίησης](docs/analysis/reference/implementation-guide.md) — components, συμβόλαια δεδομένων και κριτήρια αποδοχής.
- [Αναφορά υλοποίησης εφαρμογής](docs/analysis/reference/app-implementation-2026-10-21.md) — έλεγχοι UI/πλοήγησης και εκκρεμότητες.

- [Φωνή Xbox party](docs/analysis/reference/party-voice.md) — native ευρήματα, επικοινωνία υπηρεσιών και σχέδιο για Linux.

Οι συνθετικές δοκιμές, οι έλεγχοι με συνδεδεμένο λογαριασμό, οι φυσικές δοκιμές χειριστηρίου και η ακουστή συνομιλία μεταξύ συσκευών αποδεικνύουν διαφορετικά πράγματα. Το πλήθος ευρημάτων reverse engineering δεν είναι ποσοστό ολοκλήρωσης.
