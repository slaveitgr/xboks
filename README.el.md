# XBOKS

**Το σπίτι των παιχνιδιών υπολογιστή σας στο Linux.**

Περιηγηθείτε στη βιβλιοθήκη σας, ανακαλύψτε παιχνίδια και αποκτήστε ένα περιβάλλον παιχνιδιού φιλικό στο χειριστήριο.

Το XBOKS είναι μια ανεξάρτητη εφαρμογή Linux για παιχνίδια υπολογιστή Xbox και Microsoft Store. Συνδυάζει βιβλιοθήκη, κατάστημα, ουρά εγκατάστασης, σελίδες παιχνιδιών και προαιρετικό Game Bar επιφάνειας εργασίας. Το **XBOKS Engine** διαχειρίζεται τα υποστηριζόμενα πακέτα παιχνιδιών και το περιβάλλον Wine/Proton που χρησιμοποιείται για την εκκίνησή τους.

Το έργο βρίσκεται σε ενεργή ανάπτυξη και προς το παρόν διαθέτει πηγαίο κώδικα· δεν έχουν δημοσιευτεί δημόσια δυαδικά πακέτα. Οι διαθέσιμες ενέργειες εξαρτώνται από τον λογαριασμό, την άδεια, το πακέτο παιχνιδιού, το runtime και την επιφάνεια εργασίας σας. Το XBOKS δεν συνδέεται με τη Microsoft ή το Xbox και δεν υποστηρίζεται από αυτά.

![Αρχική σελίδα XBOKS](docs/screenshots/xboks-home.png)

*Η δική μας εφαρμογή, με δείγματα δεδομένων. Η [συλλογή εικόνων](docs/screenshots/README.md) διευκρινίζει το περιβάλλον λήψης και τα προσομοιωμένα δεδομένα υπηρεσιών. Οι εικόνες δεν αποδεικνύουν συμβατότητα παιχνιδιών.*

## Δυνατότητες

| Τα παιχνίδια σας | Τι προσφέρει το XBOKS |
| --- | --- |
| **Βιβλιοθήκη και Game Pass** | Εγκατεστημένα παιχνίδια, εισαγόμενοι φάκελοι, βιβλιοθήκη λογαριασμού και διαθέσιμοι τίτλοι Game Pass· αναζήτηση, φίλτρα, «Αναπαραγωγή αργότερα» και πρόσφατη δραστηριότητα ανά λογαριασμό. |
| **Κατάστημα** | Δημόσιες συλλογές παιχνιδιών υπολογιστή, κορυφαίων επί πληρωμή και προσθέτων, αναζήτηση, σελιδοποίηση και λεπτομέρειες συγκεκριμένου προϊόντος. Τιμές και ενδείξεις συνδρομής προέρχονται από τα δεδομένα του καταλόγου. |
| **Σελίδες παιχνιδιών** | Περιγραφές, στιγμιότυπα, εκδότης/κατηγορίες, διαθέσιμα επιτεύγματα και δραστηριότητα, κατάσταση εγκατάστασης και ταξινόμηση Xbox για φορητές συσκευές Windows, όταν παρέχεται. |
| **Ουρά εγκατάστασης** | Επιβεβαίωση πακέτου, θέση εγκατάστασης, πρόοδος, υποστηριζόμενη παύση/συνέχιση, επιλογές ακύρωσης και τοπικά διαγνωστικά. |
| **Εργαλεία εκκίνησης** | Παράμετροι και γλώσσα ανά παιχνίδι· προαιρετικά GameMode, MangoHud και Gamescope· επιλογές συμβατότητας χειριστηρίου· συντομεύσεις επιφάνειας εργασίας και Steam. Τα προαιρετικά εργαλεία εγκαθίστανται ξεχωριστά. |
| **Λογαριασμοί και κοινωνικές λειτουργίες** | Σύνδεση Microsoft, προφίλ/συνδρομή όπως επιστρέφονται από τον πάροχο, φίλοι, παρουσία, αναζήτηση παικτών και ατομικές συνομιλίες κειμένου μέσω συμβατού παρόχου. |
| **Cloud και κονσόλα** | Xbox Cloud Gaming και Remote Play κονσόλας μέσω των επίσημων προγραμμάτων αναπαραγωγής της Microsoft, με έμπιστα στοιχεία Πίσω, Επανάληψη και Κλείσιμο. Η σύνδεση στον ιστότοπο είναι ξεχωριστή από τη σύνδεση στην εφαρμογή. |
| **Ρυθμίσεις και Engine** | Ελληνικό/αγγλικό περιβάλλον, σελίδες παρόχων βιβλιοθήκης, ρυθμίσεις λήψεων/αποθήκευσης, επιλογή runtime, έλεγχοι ενημερώσεων και τοπικά διαγνωστικά. |

Ο προεπιλεγμένος φάκελος παιχνιδιών είναι **`~/Games/Xboks`**· οι προσαρμοσμένες θέσεις διατηρούνται. Τα διακριτικά λογαριασμού αποθηκεύονται μέσω του keyring του συστήματος. Η δημιουργία/ξεκλείδωμα πορτοφολιού είναι ρητή ενέργεια που χειρίζεται ο πάροχός του. Τα διαγνωστικά παραμένουν τοπικά, εκτός αν επιλέξετε να τα μοιραστείτε.

### Game Bar και πλήρης οθόνη

Ανοίξτε το Game Bar με **Ctrl+G**, `xboks --game-bar` ή το κουμπί Guide του χειριστηρίου, όταν το εκθέτει η επιφάνεια εργασίας. Το D-pad/αριστερός μοχλός μετακινεί την εστίαση, το **A** επιλέγει, το **B** επιστρέφει και τα **LB/RB** αλλάζουν ενεργή σελίδα ή καρτέλα. Ποντίκι και πληκτρολόγιο παραμένουν διαθέσιμα.

- **Γραφικά στοιχεία:** Αρχική, φίλοι/συνομιλίες, ήχος, Spotify, επιδόσεις, καταγραφές και ρυθμίσεις· επιλέξτε αγαπημένα και κρατήστε πάνελ ανοικτά όσο εμφανίζεται το Game Bar.
- **Ήχος:** Ένταση και σίγαση συσκευών/εφαρμογών PipeWire, επιλογή προεπιλεγμένης εισόδου/εξόδου και τοπική δοκιμή μικροφώνου με μετρητή στάθμης, προαιρετική ακρόαση, push to talk και υποστηριζόμενη καταστολή θορύβου. Η λήψη αρχίζει μόνο όταν τη ζητήσετε.
- **Spotify:** Έλεγχος του εγκατεστημένου προγράμματος μέσω MPRIS—αναπαραγωγή/παύση, προηγούμενο/επόμενο και υποστηριζόμενη μετακίνηση στο κομμάτι—χωρίς κωδικό Spotify ή διακριτικό Web API.
- **Επιδόσεις:** Πραγματικές μετρήσεις CPU/RAM και διαθέσιμοι μετρητές GPU/VRAM. Το GameMode ανά παιχνίδι είναι αρχικά απενεργοποιημένο και ζητά το εγκατεστημένο `gamemoderun` μόνο για το παιχνίδι· δεν αποδεικνύει βελτίωση FPS.
- **Έλεγχοι επιφάνειας εργασίας:** Διαθέσιμο Wi-Fi, συζευγμένες συσκευές Bluetooth και επιβεβαιωμένες ενέργειες συνεδρίας/τροφοδοσίας μέσω υπηρεσιών Linux.
- **Καταγραφές:** Δημιουργία και διαχείριση στιγμιοτύπων του παραθύρου XBOKS. Δεν έχουν υλοποιηθεί καταγραφή εξωτερικών παιχνιδιών και βίντεο.

Η **Λειτουργία Xbox** προσφέρει **Επανεκκίνηση**, **Έναρξη τώρα (δεν υπάρχουν αλλαγές επιδόσεων)** και **Παραμείνετε στην επιφάνεια εργασίας**. Το ρολόι και η διαθέσιμη κατάσταση μπαταρίας/τροφοδοσίας εμφανίζονται όταν επιβεβαιώνεται πλήρης οθόνη. Το άνοιγμα του διαλόγου δεν επανεκκινεί τον υπολογιστή και δεν αλλάζει ρυθμίσεις εκκίνησης.

Η προαιρετική επέκταση **GNOME Shell 51** προσθέτει μεταβάσεις Xbox/επιφάνειας εργασίας και εγγενή εναλλαγή εφαρμογών με πραγματικά παράθυρα, εικονίδια, προεπισκοπήσεις και την ανοιχτόχρωμη/σκούρα προτίμηση της επιφάνειας εργασίας. Τα **Alt+Tab**, **Alt+Shift+Tab** και **Super** λειτουργούν μέσα στην ενεργή λειτουργία· το **Ctrl+Super+Escape** επαναφέρει την επιφάνεια εργασίας. Η πειραματική ενσωμάτωση διατηρεί ενεργές την υπάρχουσα συνεδρία και τις εφαρμογές παρασκηνίου. Ξεχωριστή ελάχιστη συνεδρία παιχνιδιών παραμένει σχεδιαζόμενη.

## Εγκατάσταση

Χρειάζεται επιφάνεια εργασίας **Linux x86_64** με λειτουργικούς οδηγούς γραφικών και περιβάλλον συμβατό με Electron. Τα παιχνίδια απαιτούν επίσης ρυθμισμένο Engine/runtime και τις δικές τους εξαρτήσεις.

1. [Μεταγλωττίστε από τον πηγαίο κώδικα](#development). Το `npm run dist:deb` δημιουργεί τοπικό DEB· το `npm run dist` δημιουργεί AppImage. Οι δημόσιες λήψεις θα εμφανιστούν στη [σελίδα εκδόσεων](https://github.com/slaveitgr/xboks/releases) όταν δημοσιευτούν.
2. Σε Debian/Ubuntu, εγκαταστήστε το **DEB** με τον διαχειριστή πακέτων· για παράδειγμα, `sudo apt install ./release/FILE.deb`, αντικαθιστώντας το `FILE.deb` με το όνομα του παραγόμενου αρχείου.
3. Εναλλακτικά, κάντε το παραγόμενο **AppImage** εκτελέσιμο και ανοίξτε το σε σύστημα με λειτουργικό Chromium sandbox.
4. Ανοίξτε τις Ρυθμίσεις, ρυθμίστε/εγκαταστήστε το διαθέσιμο **XBOKS Engine** και το κοινόχρηστο runtime και συνδεθείτε από τον Λογαριασμό. Επιλέξτε συμβατό παιχνίδι και επιβεβαιώστε τη θέση εγκατάστασής του.

Το DEB προτιμάται σε συστήματα Ubuntu όπου η πολιτική AppArmor εμποδίζει την εκκίνηση AppImage. Διατηρήστε το Electron sandbox ενεργό· δείτε τον [οδηγό εγκατάστασης Linux](docs/linux-sandbox-installation.md) για αναβαθμίσεις και μεταφορά παλιών εκκινήσεων.

Οι ενημερώσεις χρησιμοποιούν το κανάλι εκδόσεων αυτού του έργου. Πρέπει να έχει δημοσιευτεί συμβατό αρχείο για να είναι διαθέσιμη η λήψη· η απουσία δημοσιευμένης ενημέρωσης δεν σημαίνει ότι το εγκατεστημένο Engine έχει πρόβλημα. Αναβαθμίστε τις εγκαταστάσεις DEB μέσω του πακέτου τους και τα AppImage μέσω της υποστηριζόμενης ροής ενημέρωσης. Δείτε τις [λήψεις και την προέλευση κώδικα](docs/engine-downloads.md).

### Προαιρετική ενσωμάτωση επιφάνειας εργασίας

Το Game Bar χρησιμοποιεί τα υπάρχοντα δικαιώματα συσκευών. Ο βοηθός παρασκηνίου ακούει συσκευές χειριστηρίου, παύει στο κλείδωμα/αναστολή και δεν αλλάζει δικαιώματα udev ούτε καταγράφει πληκτρολόγιο/ποντίκι.

Για Game Bar στις επόμενες γραφικές συνδέσεις, από αντίγραφο του πηγαίου κώδικα με εγκατεστημένο το εγγενές DEB:

```sh
python3 scripts/desktop/install-gamebar-service.py \
  --launcher /opt/xboks/xboks --enable
```

Η ενεργοποίηση εκκίνησης κατά τη σύνδεση δεν ανοίγει αμέσως την εφαρμογή. Δείτε τη [ρύθμιση Game Bar παρασκηνίου](docs/analysis/gamebar-service.md) για εκκίνηση/αφαίρεση και φορητές εγκαταστάσεις, καθώς και τον [βοηθό συντόμευσης](scripts/desktop/install-gnome-gamebar.py) για προαιρετική αντιστοίχιση Win+G.

Ο [οδηγός επέκτασης GNOME](desktop/gnome/xboks-experience@slaveitgr.github.io/README.md) καλύπτει προετοιμασία, ρητή εγκατάσταση, ενεργοποίηση και αφαίρεση. Στοχεύει μόνο το Shell 51. Μια νέα ή ενημερωμένη επέκταση χρειάζεται νέα σύνδεση GNOME για να φορτώσει τον κώδικά της· η εγκατάσταση δεν σας αποσυνδέει αυτόματα.

Οι προαιρετικές ενσωματώσεις χρησιμοποιούν υπάρχουσες υπηρεσίες: PipeWire/WirePlumber για ήχο, MPRIS για Spotify, NetworkManager για Wi-Fi, BlueZ για Bluetooth και logind για ενέργειες συνεδρίας/τροφοδοσίας. Όταν λείπουν υπηρεσίες ή δικαιώματα, τα αντίστοιχα στοιχεία παραμένουν μη διαθέσιμα.

## Τρέχοντες περιορισμοί

- **Η υποστήριξη κρίνεται ανά παιχνίδι.** Καταχώριση καταλόγου, άδεια, επιτυχημένη λήψη ή ταξινόμηση φορητού Windows δεν αποδεικνύουν συμβατότητα Linux. Μορφή πακέτου, DRM, anti-cheat, runtime και το παιχνίδι μπορούν να εμποδίσουν την εκτέλεση.
- **Η φωνή Xbox party δεν είναι συνδεδεμένη.** Τα εργαλεία μικροφώνου είναι τοπικές δοκιμές. Λίστα μελών party ή λειτουργικό μικρόφωνο δεν αποδεικνύουν φωνητική συνεδρία Xbox.
- **Οι κοινωνικές λειτουργίες έχουν μερική κάλυψη.** Έχουν δοκιμαστεί αναγνώσεις φίλων/εισερχομένων· η πραγματική παράδοση εξερχόμενων μηνυμάτων χρειάζεται ακόμη επιβεβαίωση. Ομαδικές/συστημικές συνομιλίες και μη υποστηριζόμενες ενέργειες παρόχου παραμένουν μη διαθέσιμες.
- **Η λίστα επιθυμιών cloud δεν είναι διαθέσιμη.** Προσφορές καταστήματος δεν δηλώνουν ιδιοκτησία, προσωπική έκπτωση ή πρόσβαση στη λίστα επιθυμιών. Η εξαργύρωση συνεχίζει μόνο μετά από ρητή επιλογή ανοίγματος της σελίδας Microsoft.
- **Cloud/Remote Play λειτουργούν μέσω ιστού.** Ισχύουν περιορισμοί λογαριασμού, περιοχής, συνδρομής, χειριστηρίου και browser. Το ενσωματωμένο πρόγραμμα Linux και η πλήρης ροή streaming χρειάζονται ακόμη δοκιμές· η σύνδεση της εφαρμογής δεν μεταφέρεται στον ιστότοπο.
- **Η ενσωμάτωση επιφάνειας εργασίας είναι πειραματική.** Θέση/είσοδος επικάλυψης πάνω από εξωτερικά παιχνίδια Wayland, επαναφορά παραθύρων σε διαφορετικά περιβάλλοντα, κλείδωμα/συνέχιση και πραγματική επανεκκίνηση/σύνδεση χρειάζονται επιπλέον δοκιμές. Δεν υποστηρίζονται άλλες μεγάλες εκδόσεις GNOME.
- **Καταγραφή και καρφίτσωμα έχουν όρια.** Δεν υπάρχει καταγραφή εξωτερικού παιχνιδιού/βίντεο ή προηγούμενων στιγμών· τα πάνελ κλείνουν με το Game Bar και δεν παραμένουν ως ανεξάρτητες επικαλύψεις.

<a id="roadmap"></a>
## Σχέδιο εξέλιξης

- Περισσότερες δοκιμές εγκατάστασης έως εκτέλεσης ανά παιχνίδι και σαφέστερες αναφορές συμβατότητας.
- Σηματοδοσία και μεταφορά φωνής Xbox party, με δοκιμές μεταξύ συσκευών.
- Πρόσθετες λειτουργίες καταστήματος, κοινωνικών υπηρεσιών και λογαριασμού μέσω πραγματικών παρόχων, μαζί με λίστα επιθυμιών.
- Αξιόπιστη καταγραφή εξωτερικών παιχνιδιών και καρφίτσωμα γραφικών στοιχείων στην επιφάνεια εργασίας.
- Περισσότερες δοκιμές compositor/χειριστηρίων, επαναφορά με πολλαπλές οθόνες και υποστηριζόμενες ενσωματώσεις επιφάνειας εργασίας.
- Εποπτευόμενη ελάχιστη συνεδρία παιχνιδιών, με μετρήσεις εκκίνησης, μνήμης, ενέργειας και χρόνων καρέ πριν από ισχυρισμούς επιδόσεων.

Πρόκειται για σχεδιαζόμενες κατευθύνσεις, όχι υποσχέσεις λειτουργικών δυνατοτήτων ή ημερομηνίες κυκλοφορίας.

## Μεταγλώττιση και συνεισφορά

Η εφαρμογή χρησιμοποιεί Electron, React και TypeScript. Το CI χρησιμοποιεί **Node.js 22** και npm.

```sh
git clone https://github.com/slaveitgr/xboks.git
cd xboks
npm ci
npm run dev
```

Για προεπισκόπηση με δείγματα δεδομένων, χωρίς σύνδεση ή πραγματικές ενέργειες παιχνιδιών:

```sh
XBOKS_DEMO=1 npm run dev
```

Η δοκιμαστική λειτουργία μπορεί να διαβάζει δημόσια μεταδεδομένα και εικόνες Store.

```sh
npm run build               # Έλεγχοι τύπων, δοκιμές εφαρμογής και μεταγλώττιση
npm run test:runtime-tools  # Έλεγχοι βοηθητικών runtime/μεταγλώττισης
npm run test:ci-tools       # Έλεγχοι πολιτικής εκδόσεων και διανομής
npm run dist:deb            # Δημιουργία DEB στο release/
npm run dist                # Δημιουργία AppImage στο release/
```

Το πακετάρισμα μεταγλωττίζει ξανά και δεν δημοσιεύει. Η μεταγλώττιση της εφαρμογής δεν δημιουργεί ούτε επαληθεύει κάθε εγγενές στοιχείο Engine/runtime. Ο [οδηγός Engine](scripts/BACKEND.md), ο [οδηγός κοινόχρηστου runtime](scripts/SHARED_RUNTIME.md) και ο [οδηγός συνεισφοράς](CONTRIBUTING.md) καλύπτουν επιπλέον εργαλεία και ελέγχους.

Χρησιμοποιήστε τα [ζητήματα του έργου](https://github.com/slaveitgr/xboks/issues) για αναπαραγώγιμα προβλήματα και προτάσεις. Συμπεριλάβετε εκδόσεις εφαρμογής/Engine/runtime, διανομή/επιφάνεια εργασίας, παιχνίδι και διαγνωστικά χωρίς προσωπικά στοιχεία. Μη δημοσιεύετε διακριτικά λογαριασμού ή ιδιωτικά δεδομένα πορτοφολιού.
