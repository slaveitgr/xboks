Το xboks φέρνει στο Linux ένα περιβάλλον βασισμένο στην εφαρμογή Xbox: αρχική οθόνη, περιήγηση στο Game Pass, συγκεντρωτική βιβλιοθήκη, Store, σελίδες παιχνιδιών, ουρά εγκατάστασης, ρυθμίσεις και οδηγό επιφάνειας εργασίας. Το **xboks Engine** παρέχει το διαχειριζόμενο backend και την ενσωμάτωση Proton/runtime για τα υποστηριζόμενα παιχνίδια. Η [αρχική βάση και οι άδειες](#με-βάση-τα-xodus-και-xodus-nexus) αναφέρονται παρακάτω.

> **Ανεξάρτητο έργο υπό ανάπτυξη.** Στόχος είναι η πιστή αναπαραγωγή της εμφάνισης και της συμπεριφοράς του Windows Xbox client. Η δουλειά συνεχίζεται. Το xboks είναι ανεπίσημο· δεν παρουσιάζεται ως ολοκληρωμένο αντίγραφο όλων των λειτουργιών των Windows ούτε ως λύση συμβατή με κάθε παιχνίδι.

### Φωνή: τι υπάρχει και τι ακολουθεί

Η τοπική δοκιμή μικροφώνου βρίσκεται στις ρυθμίσεις Ήχου και στην καρτέλα Ήχου του οδηγού. Η λήψη ξεκινά μόνο μετά την **Έναρξη δοκιμής**. Η ακρόαση αρχίζει απενεργοποιημένη· το κλείσιμο ή η απόκρυψη της δοκιμής ελευθερώνει το μικρόφωνο. Η επιλογή συσκευών/εξόδου και η καταστολή θορύβου εξαρτώνται από όσα εκθέτουν η επιφάνεια εργασίας και το Chromium. Ο ήχος της δοκιμής δεν καταγράφεται ούτε αποστέλλεται στο Xbox και το push to talk λειτουργεί τοπικά στο παράθυρό της.

Για ανεξάρτητη φωνητική συνομιλία σε Xbox party χρειάζονται ακόμη η σύνδεση με τις υπηρεσίες δημιουργίας/συμμετοχής και αυθεντικοποίησης, η εγγενής υπηρεσία ήχου Linux και δοκιμές μεταξύ συσκευών. Η εξάρτηση του αρχικού πακέτου `xCommsUwp` → `PartyWin` και τα πεδία ταυτότητας/δικτύου PlayFab τεκμηριώνονται στην [ανάλυση φωνής party](docs/analysis/reference/party-voice.md). Η πρόσβαση στο μικρόφωνο, μια λίστα συμμετεχόντων ή η επιτυχής μεταγλώττιση μιας βιβλιοθήκης δεν αποδεικνύουν λειτουργική φωνή Xbox.

## Ξεκίνημα

Χρειάζονται **Node 22**, npm και επιφάνεια εργασίας Linux που μπορεί να εκτελέσει Electron. Η τρέχουσα μεταγλώττιση του backend στοχεύει Linux x86_64.

```sh
git clone https://github.com/slaveitgr/xboks.git
cd xboks
npm ci
npm run dev
```

Για προεπισκόπηση με δείγματα λογαριασμού/βιβλιοθήκης:

```sh
XBOKS_DEMO=1 npm run dev
```

Το demo δεν συνδέεται σε πραγματικό λογαριασμό, δεν εγκαθιστά και δεν εκτελεί πραγματικά παιχνίδια. Μπορεί να αντλεί δημόσια δεδομένα και εικόνες από το Store.

Για κανονική χρήση, ρυθμίστε το **xboks Engine** και το κοινό runtime στις Ρυθμίσεις και συνδεθείτε από τη σελίδα Λογαριασμού. Τα υποστηριζόμενα παιχνίδια χρησιμοποιούν το επιλεγμένο Proton/runtime· η διαθεσιμότητα εξαρτάται από τα δικαιώματα λογαριασμού, τις άδειες χρήσης, τη συμβατότητα του runtime και το ίδιο το παιχνίδι. Το runtime αποθηκεύεται από προεπιλογή στο `<XDG data home>/xboks/engine/runtimes` και το backend στον φάκελο `engine/` του προφίλ xboks.

Οι έλεγχοι ενημερώσεων launcher, backend και runtime χρησιμοποιούν πλέον τα **[releases του slaveitgr/xboks](https://github.com/slaveitgr/xboks/releases)**. Δεν καταφεύγουν σε εκτελέσιμα άλλων upstream projects και οι λήψεις runtime δεν απαιτούν σύνδεση GitHub. Πρέπει να έχει δημοσιευτεί πλήρες συμβατό release του xboks για να εγκατασταθεί έτσι· η αλλαγή καναλιού δεν δημιουργεί από μόνη της releases. Η σύνδεση Microsoft, τα αρχεία παιχνιδιών, ο κατάλογος και τα απαραίτητα redistributables συνεχίζουν να χρησιμοποιούν τις πραγματικές υπηρεσίες των προμηθευτών τους. Δείτε τον [έλεγχο λήψεων και προέλευσης κώδικα](docs/engine-downloads.md).

npm run typecheck

Το `npm run build` περιλαμβάνει έλεγχο τύπων και όλες τις δοκιμές του launcher. Το `npm run dist` επαναλαμβάνει το build και δημιουργεί AppImage στον φάκελο `release/`· δεν δημοσιεύει GitHub release. Ένα επιτυχημένο πακέτο σε έναν υπολογιστή δεν επιβεβαιώνει συμβατότητα με κάθε διανομή Linux.

### Προαιρετικό social companion — backend 0.3.0

Οι φίλοι/συνομιλίες χρησιμοποιούν το επιλεγμένο backend όταν αυτό υποστηρίζει social. Ένα πακέτο μπορεί εναλλακτικά να περιλαμβάνει το **social companion 0.3.0**, χωρίς αντικατάσταση του backend παιχνιδιών. Διαβάζει τα υπάρχοντα συμβατά διαπιστευτήρια λογαριασμού χωρίς εγγραφή ή ανανέωσή τους· αν έχουν λήξει, απαιτείται η κανονική ανανέωση/σύνδεση από τον Λογαριασμό.

Για μεταγλώττιση του companion από την καθορισμένη έκδοση πηγαίου κώδικα, χρησιμοποιήστε το Rust toolchain του [`assets/backend-source.lock.json`](assets/backend-source.lock.json) και τις εξαρτήσεις του [`scripts/BACKEND.md`](scripts/BACKEND.md), μαζί με το `protoc`:

```sh
mkdir -p work outputs
node scripts/build-backend.mjs --work work/social-build --output outputs/social-backend
node scripts/bundle-social-backend.mjs \
  --binary work/social-build/target/release/xodus-cli \
  --license work/social-build/source/LICENSE \
  --source-archive outputs/social-backend/xboks-engine-backend-0.3.0-linux-x86_64-source.tar.xz
npm run dist
```

Το εσωτερικό αποτέλεσμα μεταγλώττισης Cargo διατηρεί το όνομα `xodus-cli`· το εργαλείο συσκευασίας αποθηκεύει τα επαληθευμένα bytes ως `xboks-engine`. Οι φάκελοι εργασίας/εξόδου πρέπει να είναι νέοι· το εργαλείο συσκευασίας επίσης αρνείται να αντικαταστήσει το `assets/social-backend/`. Τα παραγόμενα εκτελέσιμα και το αρχείο του αντίστοιχου πηγαίου κώδικα μένουν εκτός Git. Το companion ελέγχεται με hash και περιορισμένο έλεγχο βοήθειας, δεν χρησιμοποιείται για σύνδεση ή εκτέλεση παιχνιδιών και δεν ενεργοποιεί φωνή party. Οι εξαρτήσεις OpenSSL 4/glibc του τοπικού companion και τα όρια επαλήθευσης καταγράφονται στην [αναφορά social/συστήματος](docs/analysis/social-system-integration.md).

## Fullscreen Experience & Game Bar

**Η 0.3.20 επεκτείνει το προαιρετικό Fullscreen Experience του GNOME Shell 51 με την επέκταση v4, το θέμα επιφάνειας εργασίας και ρητές επιλογές εισόδου.** Στο παράθυρο επιφάνειας εργασίας, επάνω δεξιά εμφανίζεται μόνο το κουμπί **Λειτουργία Xbox**. Σε πλήρη οθόνη, αντικαθίσταται από το ρολόι και τη διαθέσιμη κατάσταση μπαταρίας/τροφοδοσίας. Ποσοστό, φόρτιση και εξωτερική τροφοδοσία προέρχονται από το Linux· οι άγνωστες τιμές παραμένουν άγνωστες. Δίπλα στο κουμπί εισόδου δεν εμφανίζονται ρολόι επιφάνειας εργασίας ή επινοημένη ένδειξη φόρτισης.

### Επιλογή εισόδου σε λειτουργία Xbox

Το ελληνικό/αγγλικό παράθυρο ακολουθεί τη λευκή κεντρική κάρτα του screenshot 110 με τρεις επιλογές τη μία κάτω από την άλλη. Το άνοιγμά του διαβάζει μόνο τις διαθέσιμες δυνατότητες· δεν γράφει ρυθμίσεις εκκίνησης, δεν εισέρχεται σε πλήρη οθόνη και δεν επανεκκινεί.

- Η **Επανεκκίνηση** προετοιμάζει νέα επιβεβαίωση με λήξη και ζητά πραγματική επανεκκίνηση Linux μέσω logind. Απαιτεί εγκατεστημένο μόνιμο launcher, διαθέσιμη ενσωμάτωση GNOME, αδρανή εστιασμένη εφαρμογή και τρέχουσα δυνατότητα επανεκκίνησης. Μια ελεγχόμενη εγγραφή του συγκεκριμένου προφίλ επιτρέπει μία προσπάθεια εισόδου σε λειτουργία Xbox μετά τη σύνδεση που ακολουθεί την επανεκκίνηση. Η απόρριψη του αιτήματος αναιρεί αυτήν την εγγραφή· δεν αλλάζει την επιλεγμένη συνεδρία επιφάνειας εργασίας.
- Η **Έναρξη τώρα (δεν υπάρχουν αλλαγές επιδόσεων)** χρησιμοποιεί αμέσως την υπάρχουσα ενσωμάτωση παραθύρου/πλήρους οθόνης, χωρίς επανεκκίνηση.
- Το **Παραμείνετε στην επιφάνεια εργασίας** κλείνει το παράθυρο χωρίς είσοδο σε λειτουργία Xbox.

Η πλοήγηση χειριστηρίου περιορίζεται στο παράθυρο. Το **B/Escape** ακυρώνει όσο προετοιμάζεται μόνο το token επιβεβαίωσης. Μετά την αποστολή αιτήματος εισόδου ή επανεκκίνησης, η παραμονή και η ακύρωση απενεργοποιούνται μέχρι να επιστρέψει αποτέλεσμα· αποτυχία εμφανίζεται τοπικά και επιτρέπει ξανά επιλογές. Η επανεκκίνηση του GNOME **δεν** εφαρμόζει πρόσθετες βελτιστοποιήσεις επιδόσεων. Η πραγματική επανεκκίνηση και η επόμενη σύνδεση/εκκίνηση χρειάζονται ακόμη φυσική δοκιμή.

Όταν η επέκταση έχει εγκατασταθεί, αναγνωριστεί από το GNOME και ενεργοποιηθεί, ρητό αίτημα από το εστιασμένο παράθυρο xboks μπορεί να κρύψει προσωρινά τα υποστηριζόμενα στοιχεία του GNOME Shell. Η μόνιμη τοπική σύνδεση της εφαρμογής διατηρεί τη λειτουργία και την αποδεσμεύει κατά την έξοδο ή την απώλεια σύνδεσης. Το **Ctrl+Super+Escape** είναι η συντόμευση επαναφοράς έκτακτης ανάγκης· για είσοδο πρέπει να είναι διαθέσιμη. Το κλείδωμα ή η απενεργοποίηση της επέκτασης επαναφέρουν επίσης τις αλλαγές της. Το ξεκλείδωμα δεν ενεργοποιεί ξανά αυτόματα τη λειτουργία.

Οι υπάρχουσες εφαρμογές, ο compositor GNOME και οι υπηρεσίες επιφάνειας εργασίας συνεχίζουν να εκτελούνται. Η λειτουργία **δεν** ελευθερώνει τη RAM τους, δεν τερματίζει εφαρμογές παρασκηνίου και δεν δημιουργεί ξεχωριστή gaming συνεδρία. Χωρίς την επέκταση, παραμένει διαθέσιμη η απλή πλήρης οθόνη παραθύρου και η εφαρμογή ενημερώνει ότι η λειτουργία Xbox του συστήματος δεν είναι διαθέσιμη. Η πλήρης οθόνη ενός παραθύρου δεν αποδεικνύει ενεργή ενσωμάτωση GNOME.

### Εγγενής εναλλαγή παραθύρων στη λειτουργία Xbox

Με φορτωμένη την **επέκταση GNOME v4**, το **Alt+Tab** προχωρά από το ενεργό παράθυρο, το **Alt+Shift+Tab** κινείται αντίστροφα και η απελευθέρωση του Alt ενεργοποιεί το επιλεγμένο παράθυρο. Το σκέτο **Super** κρατά ανοικτή την πλήρη οθόνη εναλλαγής μέχρι ρητή επιλογή ή κλείσιμο. Οι χειρισμοί ισχύουν μόνο όσο το xboks διατηρεί τη δική του λειτουργία Xbox· εκτός αυτής, οι συντομεύσεις της επιφάνειας εργασίας λειτουργούν κανονικά.

Εμφανίζονται πραγματικά ανοικτά παράθυρα, εγγενή εικονίδια εφαρμογών **32 pixel** και διαθέσιμες ζωντανές προεπισκοπήσεις. Οι κάρτες διατηρούν την αναλογία του εγγενούς παραθύρου και ακολουθούν τις μετρήσεις των screenshots. Τα **LB/RB** ή αριστερά/δεξιά επιλέγουν παράθυρο, το **A/Enter** το ενεργοποιεί, το **B/Escape** κλείνει την εναλλαγή και το **X** ζητά από την επιλεγμένη εφαρμογή να κλείσει κανονικά. Πάνω/κάτω επιλέγει τα κάτω κουμπιά **Λειτουργία Xbox / Επιφάνεια εργασίας**: το Xbox εστιάζει στο υπάρχον παράθυρο xboks και η Επιφάνεια εργασίας αποδεσμεύει τη λειτουργία Xbox. Το κλείσιμο παραθύρου δεν τερματίζει βίαια τη διεργασία του.

Όσο ισχύει αυτή η λειτουργία, τα κανονικά παράθυρα εφαρμογών μπαίνουν προσωρινά σε πλήρη οθόνη και δεν παραμένουν ελαχιστοποιημένα. Η Επιφάνεια εργασίας, το κλείδωμα, η απώλεια ιδιοκτησίας ή η απενεργοποίηση της επέκτασης επαναφέρουν τις αποθηκευμένες καταστάσεις παραθύρων μαζί με τα στοιχεία Shell. Αυτή η πολιτική και η φυσική χρήση Alt+Tab παραμένουν ανεπιβεβαίωτες σε πραγματική συνεδρία Shell v3.

Η **Έναρξη τώρα** και η εγγενής εναλλαγή λειτουργούν μέσα στην τρέχουσα συνεδρία GNOME. Οι εφαρμογές παρασκηνίου συνεχίζουν να εκτελούνται και δεν δημιουργείται ξεχωριστή gaming συνεδρία. Πραγματική επανεκκίνηση γίνεται μόνο με τη χωριστή, ρητή επιλογή **Επανεκκίνηση** παραπάνω· καμία διαδρομή δεν υπόσχεται πρόσθετη βελτιστοποίηση επιδόσεων GNOME. Η ξεχωριστή εποπτευόμενη gaming συνεδρία παραμένει διαφορετικός μελλοντικός στόχος.

Η εναλλαγή ακολουθεί το θέμα επιφάνειας εργασίας GNOME: λευκή επιφάνεια στο προεπιλεγμένο/ανοιχτό θέμα, μαύρο ακτινωτό φόντο και κυανό περίγραμμα στο σκούρο. Η αλλαγή εφαρμόζεται όσο είναι ανοικτή, διατηρώντας τις πραγματικές προεπισκοπήσεις παραθύρων.

### Εγκατάσταση προαιρετικής επέκτασης GNOME

Από το source checkout σε **GNOME Shell 51**, επιλέξτε νέο φάκελο προετοιμασίας:

```sh
python3 scripts/desktop/stage-gnome-experience.py \
  --output work/gnome-experience/install-stage --install
```

Το εργαλείο ελέγχει την έκδοση Shell, αρνείται υπάρχοντα φάκελο επέκτασης και εγκαθιστά την επέκταση **ανενεργή**. Δεν την ενεργοποιεί, δεν εισέρχεται σε λειτουργία Xbox, δεν αλλάζει ρυθμίσεις επιφάνειας εργασίας και δεν τερματίζει τη συνεδρία. Χωρίς `--install`, προετοιμάζει μόνο τα αρχεία. Άλλες κύριες εκδόσεις GNOME δεν υποστηρίζονται από αυτό το πρωτότυπο.

Το πακέτο περιλαμβάνει επίσης τον πηγαίο κώδικα της επέκτασης και το εργαλείο εγκατάστασης. Από αποσυμπιεσμένο AppImage που περιέχει φάκελο `resources/`, η αντίστοιχη εντολή είναι:

```sh
python3 resources/desktop/stage-gnome-experience.py \
  --source resources/gnome-extension/xboks-experience@slaveitgr.github.io \
  --output /tmp/xboks-experience-install-stage --install
```

Ο φάκελος εξόδου πρέπει να είναι νέος· καμία εντολή δεν αντικαθιστά υπάρχουσα επέκταση.

Μια **νέα τοπική επέκταση χρειάζεται νέα συνεδρία GNOME για να αναγνωριστεί**. Η ενημέρωση ήδη φορτωμένης v1/v2/v3 στη **v4** απαιτεί επίσης νέα συνεδρία Shell: η απενεργοποίηση και ενεργοποίηση του ίδιου UUID στην τρέχουσα συνεδρία δεν φορτώνει το νέο JavaScript. Η εντολή προετοιμασίας αρνείται υπάρχοντα φάκελο· ελέγξτε τα νέα αρχεία πριν αντικαταστήσετε εγκατεστημένο αντίγραφο. Αποθηκεύστε την εργασία σας και αποσυνδεθείτε/συνδεθείτε ξανά όταν το επιλέξετε· δεν γίνεται αυτόματη αποσύνδεση ή επανεκκίνηση κατά την εγκατάσταση ή το άνοιγμα του παραθύρου επιλογών. Το θέμα επιφάνειας εργασίας απαιτεί φορτωμένη v4· οι συντομεύσεις και η πολιτική παραθύρων απαιτούν τουλάχιστον v3. Μετά τη νέα σύνδεση:

```sh
gnome-extensions enable xboks-experience@slaveitgr.github.io
gnome-extensions info xboks-experience@slaveitgr.github.io
```

Η ενεργοποίηση κάνει διαθέσιμη την ενσωμάτωση· η είσοδος γίνεται όταν επιλέξετε **Λειτουργία Xbox** στο xboks. Για απενεργοποίηση της επέκτασης:

```sh
gnome-extensions disable xboks-experience@slaveitgr.github.io
```

Δείτε τις [οδηγίες και το πρωτόκολλο επέκτασης](desktop/gnome/xboks-experience@slaveitgr.github.io/README.md) και την [αρχιτεκτονική συνεδριών Linux](docs/analysis/fullscreen-experience-linux.md). Η ξεχωριστή gaming συνεδρία Gamescope/Kiosk για τη διανομή παραμένει επόμενο βήμα. Το `XBOKS_FULLSCREEN_EXPERIENCE=1` δηλώνει ήδη διαμορφωμένη συνεδρία διανομής· η απλή δήλωσή του δεν δημιουργεί τέτοια συνεδρία.

Οι αυτοματοποιημένες δοκιμές καλύπτουν ιδιοκτησία/επαναφορά, προσομοιωμένη συμπεριφορά Shell, τον πραγματικό GJS helper με ελεγχόμενη υπηρεσία σε απομονωμένο D-Bus, μεταβάσεις πλήρους οθόνης, ελέγχους εκκίνησης/επανεκκίνησης και καταστάσεις μπαταρίας/επάνω γραμμής. Το παράθυρο εισόδου περνά **49 ελέγχους σε πραγματικό Chromium με συνθετική διεπαφή**, με περιορισμένα D-pad/A/B, λήξη επιβεβαίωσης, ακύρωση κατά την προετοιμασία και αποκλεισμό ακύρωσης μετά την αποστολή αιτήματος. Είναι **δοκιμές με ελεγχόμενα δεδομένα και έλεγχοι πρωτοκόλλου**· καμία δεν επανεκκινεί το PC. Η πραγματική επαναφορά panel/dock/παραθύρων στη v3, το κλείδωμα/ξεκλείδωμα, οι πολλαπλές οθόνες, το φυσικό Alt+Tab και η πραγματική επανεκκίνηση/σύνδεση χρειάζονται ακόμη δοκιμές αποδοχής.

### Πλοήγηση χειριστηρίου και Game Bar

Το D-pad/αριστερός μοχλός μετακινεί την εστίαση, το A επιλέγει, το B επιστρέφει και τα LB/RB αλλάζουν την ενεργή σελίδα, καρτέλα ή ενότητα του οδηγού. Ποντίκι και πληκτρολόγιο παραμένουν διαθέσιμα. Ανοίξτε τον οδηγό από το κουμπί της εφαρμογής, με **Ctrl+G** μέσα στην εφαρμογή, με το κουμπί Guide όταν το εκθέτει το λειτουργικό ή με **`--game-bar`**. Στο Ubuntu/Debian, εγκαταστήστε το εγγενές DEB και αντιστοιχίστε το **Win+G** στο GNOME στη σταθερή εκκίνησή του:

```sh
python3 scripts/desktop/install-gnome-gamebar.py \
  --command '/opt/xboks/xboks --game-bar'
```

Η διαδικασία στο παρασκήνιο ακούει το Linux `BTN_MODE` από επαληθευμένα χειριστήρια με ήδη διαθέσιμη άδεια ανάγνωσης. Τα υπόλοιπα κουμπιά πλοήγησης και οι μοχλοί γίνονται δεκτά μόνο για το ορατό, εστιασμένο Game Bar ή την εγγενή εναλλαγή της ενεργής λειτουργίας Xbox· στο παρασκήνιο λειτουργεί μόνο το κουμπί Guide. Η είσοδος παύει στο κλείδωμα/αναστολή, χωρίς αποκλειστική δέσμευση συσκευών, αλλαγή δικαιωμάτων udev ή καταγραφή πληκτρολογίου/ποντικιού. Κάθε ενέργεια ελέγχει την ενεργή ξεκλείδωτη τοπική γραφική συνεδρία. Το polling του browser παραμένει εφεδρικό μόνο σε εστιασμένο παράθυρο και σταματά όσο την ίδια επιφάνεια χειρίζεται η εγγενής είσοδος, ώστε να αποφεύγονται διπλές ενέργειες.

Η Αρχική του Game Bar εμφανίζει την πραγματική προηγουμένως εστιασμένη εφαρμογή όταν την παρέχει η **επέκταση GNOME v3**· το κουμπί επιστροφής κλείνει τον οδηγό αντί να ανοίγει κάποιο άσχετο παιχνίδι. Τα πρόσφατα παιχνίδια προκύπτουν μόνο από έγκυρες χρονικές ενδείξεις στο τοπικό ιστορικό του τρέχοντος λογαριασμού, όχι από τα πρώτα εγκατεστημένα παιχνίδια. Τα δεδομένα που λείπουν δεν επινοούνται.

Αριστερά/δεξιά αλλάζει τα πραγματικά sliders έντασης συστήματος, μείκτη συσκευών/εφαρμογών και διαφάνειας Ρυθμίσεων. Η αναμονή αλλαγής ήχου διατηρεί την εστίαση και αποκλείει πρόσθετες αλλαγές· πάνω/κάτω επιτρέπει έξοδο και η ολοκλήρωση δεν κλέβει ξανά την εστίαση. Τα όρια διατηρούν την οριζόντια εστίαση χωρίς διπλές εγγραφές. Ο ξεχωριστός renderer περνά **68 ελέγχους σε πραγματικό Chromium με συνθετική είσοδο**, με καθυστερημένες απαντήσεις backend και εγγενή είσοδο χωρίς έκθεση χειριστηρίου από το Chromium. Δείτε το [αναπαραγώγιμο fixture εισόδου](scripts/ui/fixtures/guide-controller.tsx). Ο χρήστης επιβεβαίωσε τη βασική πλοήγηση με φυσικό χειριστήριο στην **0.3.18** και τη διατήρηση εστίασης/ρύθμιση έντασης συστήματος στην **0.3.19**. Οι διαφορετικές συσκευές μείκτη και η συμπεριφορά πάνω από πραγματικά παιχνίδια χρειάζονται ακόμη φυσική δοκιμή.

Το εργαλείο συντόμευσης διατηρεί τις άλλες αντιστοιχίσεις και αρνείται υπάρχουσα σύγκρουση Win+G. Το Game Bar παραμένει ξεχωριστό παράθυρο Electron· η επέκταση v3 παρέχει περιορισμένη ενεργοποίηση του συγκεκριμένου έμπιστου παραθύρου μέσω compositor. Η ανοιχτόχρωμη εναλλαγή παραθύρων είναι εγγενές στοιχείο GNOME. Αυτό δεν αποδεικνύει καθολική εμφάνιση/είσοδο Game Bar πάνω από εξωτερικά παιχνίδια στο Wayland, η οποία χρειάζεται ακόμη δοκιμές. Η ένταση συστήματος χρησιμοποιεί PipeWire/WirePlumber (`wpctl`)· τα στιγμιότυπα καταγράφουν το παράθυρο xboks, όχι οποιοδήποτε παιχνίδι ή ολόκληρη την επιφάνεια εργασίας.

Το μενού γραφικών στοιχείων διαχειρίζεται αγαπημένα και πάνελ που παραμένουν ανοικτά όσο φαίνεται το Game Bar. Οι ρυθμίσεις καλύπτουν γενική συμπεριφορά, θέμα/διαφάνεια, είσοδο, ορατότητα στοιχείων και ξεχωριστές σελίδες λογαριασμού, απορρήτου, ειδοποιήσεων και προσβασιμότητας. Οι μη διαθέσιμες λειτουργίες εξηγούν ποια σύνδεση υπηρεσίας λείπει. Οι επεκτάσεις Game Bar των Windows δεν εγκαθίστανται ως γραφικά στοιχεία Linux.

Το Spotify χρησιμοποιεί το MPRIS του εγκατεστημένου προγράμματος μέσω τοπικού βοηθητικού GJS, χωρίς προσθήκη κωδικού, OAuth token ή πρόσβασης στο Web API. Πρόγραμμα που δεν εκτελείται και μη υποστηριζόμενοι έλεγχοι παραμένουν μη διαθέσιμα. Το πρωτόκολλο έχει δοκιμαστεί με απομονωμένη υπηρεσία· η πραγματική αναπαραγωγή Spotify μένει να επιβεβαιωθεί. Οι Επιδόσεις διαβάζουν πραγματικούς μετρητές και η Συλλογή διαχειρίζεται μόνο PNG του xboks. Το κλείσιμο του Game Bar κρύβει όλα τα πάνελ του.

Ο μείκτης διαβάζει τις πραγματικές συσκευές και ροές εφαρμογών του PipeWire και ελέγχει την τρέχουσα ταυτότητά τους πριν από αλλαγή έντασης, σίγασης ή προεπιλεγμένης εισόδου/εξόδου. Η πραγματική ανάγνωση κατάστασης δοκιμάστηκε επιτυχώς· οι αλλαγές ελέγχθηκαν με απομονωμένα δεδομένα. Η ξεχωριστή δοκιμή μικροφώνου διατηρεί δικό της έλεγχο άδειας και διάρκειας λήψης.

Για Game Bar στο παρασκήνιο στις επόμενες γραφικές συνδέσεις, εγκαταστήστε την [υπηρεσία χρήστη](docs/analysis/gamebar-service.md):

```sh
python3 scripts/desktop/install-gamebar-service.py \
  --launcher /opt/xboks/xboks --enable
```

Η εντολή ενεργοποιεί την εκκίνηση σε επόμενη είσοδο χωρίς να ξεκινά ή να σταματά την τρέχουσα εφαρμογή. Το `--start` είναι ξεχωριστή ρητή επιλογή. Η υπηρεσία εκκινεί χωρίς το κυρίως παράθυρο και το κλείσιμο του παραθύρου διατηρεί την κοινή διεργασία. Η ρητή Έξοδος ή η διακοπή της υπηρεσίας κλείνει εφαρμογή και παιχνίδια. Αν παλιότερο στιγμιότυπο κατέχει ήδη το προφίλ, δέχεται το αίτημα· σε νέα είσοδο η υπηρεσία μπορεί να κατέχει την κύρια διεργασία. Αφαίρεση της επαληθευμένης μονάδας γίνεται με `python3 scripts/desktop/install-gamebar-service.py --uninstall`. Η παραμονή στη συνεδρία δεν αποτελεί overlay του compositor.

Το Remote Play παραμένει πλέον μέσα στον launcher με απομονωμένη προβολή του επίσημου web client. Ο λογαριασμός Microsoft της ιστοσελίδας παραμένει ξεχωριστός από τη σύνδεση του launcher. Η [ανάλυση του αρχικού Windows client](docs/analysis/reference/remote-play-ownership.md) αποδεικνύει εσωτερική διαδρομή κονσόλας και native `GameStreamView`· η δική μας σύνδεση με το web δεν ανακατασκευάζει αυτές τις υπηρεσίες. Η ανακοίνωση μετάβασης σε browser αφορά ρητά την αφαίρεση από την εφαρμογή κινητών, όχι την αφαίρεση του συγκεκριμένου Windows client. Ανακάλυψη/αφύπνιση κονσόλας, ήχος/εικόνα και πραγματικό gameplay με χειριστήριο στο Xbox One X παραμένουν ανεπιβεβαίωτα.

## Ανακατασκευή και επαλήθευση

Η οπτική αναφορά είναι η **εφαρμογή Xbox Windows 2610.1001.20.0 σε Xbox mode** και τα στιγμιότυπα που έχουν δοθεί. Η [βιβλιοθήκη αναφοράς](docs/analysis/reference/README.md) συνδέει παρατηρήσεις από screenshots, αποκωδικοποιημένους πόρους, κανόνες ελέγχων/πλοήγησης, native μεταδεδομένα και οδηγίες υλοποίησης. Ο [πίνακας επαλήθευσης](docs/analysis/reference/verification-matrix.json) διαχωρίζει στατικά ευρήματα, παρατηρήσεις στα Windows και δοκιμασμένη συμπεριφορά στο Linux.

Αφετηρίες:

- [Οδηγός υλοποίησης](docs/analysis/reference/implementation-guide.md) — components, συμβόλαια δεδομένων και κριτήρια αποδοχής.
- [Αναφορά υλοποίησης εφαρμογής](docs/analysis/reference/app-implementation-2026-10-21.md) — έλεγχοι UI/πλοήγησης και εκκρεμότητες.
- [Ενσωμάτωση social/συστήματος](docs/analysis/social-system-integration.md) — πραγματικές συνδέσεις υπηρεσιών, αναγνώσεις με λογαριασμό, πακέτα και περιορισμοί.
- [Φωνή Xbox party](docs/analysis/reference/party-voice.md) — native ευρήματα, επικοινωνία υπηρεσιών και σχέδιο για Linux.
- [Native γραφικά στοιχεία και ρυθμίσεις Game Bar](docs/analysis/reference/gamebar-widgets.md) — XBF/ελληνικοί πόροι, ακριβείς έλεγχοι, όρια Spotify και πίνακας υποστήριξης/εκκρεμοτήτων Linux.
- [Υπηρεσία Game Bar στο παρασκήνιο](docs/analysis/gamebar-service.md) — προαιρετική ενεργοποίηση στην είσοδο, κοινή διεργασία, τερματισμός και αφαίρεση.
- [Αρχική υλοποίηση Remote Play](docs/analysis/reference/remote-play-ownership.md) — αποδείξεις εσωτερικής native διαδρομής/player και όρια της σύνδεσης με τον επίσημο browser client.

Οι συνθετικές δοκιμές, οι έλεγχοι με συνδεδεμένο λογαριασμό, οι φυσικές δοκιμές χειριστηρίου και η ακουστή συνομιλία μεταξύ συσκευών αποδεικνύουν διαφορετικά πράγματα. Το πλήθος ευρημάτων reverse engineering δεν είναι ποσοστό ολοκλήρωσης.
