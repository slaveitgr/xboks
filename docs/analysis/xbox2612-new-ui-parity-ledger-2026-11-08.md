# Xbox 2612 new-experience parity ledger

Checkpoint: 2026-11-08. Target: the supplied **Microsoft.GamingApp 2612.1001.23.0** new CE experience. This is a bounded implementation checklist, **not complete reverse engineering or a claim of Windows parity**. It combines pinned package/source analysis with a new, bounded navigation walk of the already-running original client under Wine. This turn observed Home, the account menu, Profile, Library Installed, six Settings categories and the Store landing. Navigation used the owned client surface; it did not perform account writes, launch games, complete purchases or establish Windows service parity. Private account-bearing captures remain outside Git.

The XBOKS counterpart column describes the current development source, declared version 0.3.31, based on repository revision `1bfb8fb27889e069b7db1c25bb99f6f5741a8507` plus the ongoing working changes. A counterpart's existence does not mean its layout, services or transitions match the original.

## Validation of the current reconstruction

The accepted functional renderer pass completed **177 checks, zero failures and 59 screenshots**, with no browser errors, forbidden actions, unexpected APIs or source drift. It covers Store Browse/Deals and category services, nested Back/focus, retained Game Pass page-two/genre state, Refresh after continuation, account changes, Remote Play navigation, Settings and async controller sliders. The accepted run is `work/redesign-2026-11/new-experience-functional-final-0.3.31-v2/experience-redesign-report.json`, with report SHA256 `c565b6daf207aa9e93bacda2fcdf4e55f4027ef1fa650eb2c84adf2a9a0c1ae6` and source-fingerprint SHA256 `1c4cd22977ab8124ab31bd6ad10e86e52e725326e6f05c10bbabbdaf2b74263b`. Earlier final-5 and interrupted attempts are superseded for this source. Unmodified labeled fixture images and relative source fingerprints are published in the [gallery](../screenshots/README.md).

The former Spotify failure was reproduced as a signal/request read race and fixed with serialized reads plus a deterministic regression. The integrated browser also exposed a Game Pass refresh-cursor defect after pagination; its regression failed before the fix and passed afterward. Final whole-suite and package evidence is recorded in the [0.3.31 implementation checkpoint](xboks-0.3.31-implementation.md). Typechecks pass. Renderer/unit fixtures do not establish original Windows pixel parity, live party voice, One X streaming or native OS overlay acceptance. Separate anonymous production-adapter checks did verify advancing GR Deals and Cozy collection delivery, without an account or game operation.
