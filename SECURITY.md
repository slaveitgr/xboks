# XBOKS security policy

XBOKS is under active development. There is no fixed security support window or
claim that arbitrary game packages are safe.

Report suspected vulnerabilities privately to the repository maintainer before
publishing exploit details. Never include passwords, tokens, account responses,
cloud-save contents or private diagnostics in public issues or screenshots.

Account credentials belong in the system wallet. The launcher must not export
them into its UI or logs. Compatibility-runtime and game processes use the
current user's permissions. Cloud-save features can change remote and local
saves; test them only with explicit ownership and recoverable backups.
